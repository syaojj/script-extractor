# 스크립트-추출기

수능 SYNC 교재 PDF에서 **문제/어휘를 자동 추출**하는 브라우저 도구입니다.
설치·서버·업로드 없이 **`스크립트-추출기-v3.html`을 브라우저로 열고 PDF를 끌어다 놓으면** 바로 결과를 받을 수 있습니다.

> 모든 처리는 브라우저 안에서만 이루어집니다. PDF가 외부로 업로드·전송되지 않습니다. (PDF 엔진 [pdf.js](https://mozilla.github.io/pdf.js/)가 파일 안에 내장되어 오프라인 동작)

## 하나의 파일로 학생용 + 해설 모두

`스크립트-추출기-v3.html` 진입 시 **학생용 / 해설** 중 선택하면, 선택에 맞는 추출기가 동작합니다.

| 선택 | 대상 | 추출 내용 |
|------|------|-----------|
| **학생용 (내지)** | 내지 PDF | 문제 번호·지시문·지문·보기 (+ 미니 모의고사는 어원 어휘) · **보기 추출 ON/OFF 토글** |
| **해설** | 해설 PDF | 문항별 어휘(문항번호·영어단어·한글뜻) |

## 사용법

1. `스크립트-추출기-v3.html`을 **더블클릭**해 브라우저에서 엽니다. (최신 Chrome/Edge 권장)
2. **학생용 / 해설** 중 종류를 선택합니다.
3. 해당 **PDF를 화면에 끌어다 놓습니다** (또는 파일 선택).
4. 결과를 확인하고 **TXT · 워드(.doc) · 엑셀(.csv) · 한글(.hwpx)** 중 원하는 형식으로 내려받습니다.

## 지원 교재 (학생용 내지)

PDF를 넣으면 판형을 자동 감지합니다.

- 미니 모의고사 — 문제 + 어휘(어원)
- 영어독해 10+1회 / 독해 모의고사 15회 — 문제
- 문법어법어휘 150제 / 어법어휘 228제 — 문제

> 어법·낱말 유형 문항은 보기가 지문 속 밑줄(①~⑤)이라 기본적으로 보기를 제외합니다. (보기 토글로 조절 가능)

## 참고

- 장문 세트의 2번째 문항은 지문을 공유하므로 지문이 비어 보일 수 있습니다.
- 일부 도표·안내문 문항은 선택지가 5개를 초과해 잡힐 수 있습니다.
- `.hwpx`는 한글 프로그램에서 열어 확인을 권장합니다.
